# use_xhs

打开小红书是一种具体的外部能力：低头划屏，看推荐流、搜索关键词、读取帖子和作者主页里的事实，
看看自己发过的内容与公开互动数据，或查看评论/回复、点赞和关注通知（不包含私信），
也可以对同一工具环里已经看见的帖子做很低频、很克制的互动。

它适合用在想看看陌生人的生活、找一点灵感、搜索旅行/餐厅/经验贴，或确认小红书里某个事实时。
它也容易让注意力被带走，所以看到一点就要知道回来；刷够了、没什么可看的，或者外部能力不可用时，
就诚实收住，不要编造帖子或搜索结果。

互动也不是随手乱点：评论和回复只能引用已有 XHS `artifact_ref`，不要把评论正文直接传给工具；点赞和
收藏只针对本轮工具刚返回的 `feed_ref`；回复或点赞评论还必须使用本轮详情/通知返回的
`comment_ref`。工具返回 already_done 时不要重复操作；任何工具返回失败或结果未知时都诚实收住，
不要写成已经互动成功。
